# Jarvis: голосовой Invoker для Umbrella

Называешь спелл или предмет голосом, скрипт сам инвокает и кастует.

## Установка

Нужны два файла со страницы [Releases](https://github.com/gdhost4-eng/umbrella-invoker-jarvis/releases):

1. `invoker_jarvis.lua` положи в папку `scripts` Umbrella и перезагрузи скрипты.
2. `Jarvis.exe` запусти. Ставить ничего не надо, значок появится в трее.
   Первый запуск занимает несколько минут: помощник один раз докачивает модель распознавания.
3. В игре включи скрипт: Heroes → Invoker → Jarvis → «Включить».

Микрофон выбирается в меню значка в трее. Играй в наушниках.

## Команды

Сначала обращение: «Джарвис, санстрайк». После него 10 секунд можно говорить без обращения,
несколько команд подряд: «блинк метеор бласт».

| Скажи | Что произойдет |
|---|---|
| «санстрайк», «метеор», «колд снэп», «торнадо», «эмп», «алакрити», «гост волк», «айс волл», «форджи», «бласт» | вызвать и применить спелл |
| «скастуй метеор» | только вызвать спелл |
| «катаклизм» | Sun Strike на себя |
| «алакрити на союзника» | Alacrity на героя у курсора |
| «бкб», «блинк», «еул», «хекс», «дагон», «рефрешер», … | предмет по названию |
| «еул на себя», «форс на себя», … | предмет на себя |
| «первый … шестой слот», «нейтралка» | предмет из слота |
| «тп», «тпаут» | ТП с прицелом, ТП на фонтан |
| «квас», «векс», «экзорт» | три сферы |
| «качай экзорт» | прокачка |
| «комбо 1» … «комбо 12» | запустить комбо из сборщика комбо Umbrella |
| «комбо динамик» | запустить динамическое комбо |
| «стоп», «холд» | стоп, холд |
| «мут», «включись» | выключить и включить прослушивание |
| «спи» | заснуть до следующего «Джарвис» |
| «выключись» | закрыть помощника |

Комбо ведет встроенный скрипт Invoker: Jarvis переключает слот и зажимает его клавишу комбо.
Правый клик куда угодно или «стоп» отменяет прокаст. В меню Invoker должна быть задана Combo Key.
Номера работают до числа комбо, выбранного там же в Combo Slots: до 6 или до 12.
